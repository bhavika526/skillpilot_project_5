# SkillPilot Project 5 - Landing Page with Animated Hero Section

A simple landing page built as part of my SkillPilots program. The hero section is animated with CSS `@keyframes`, using a fade-in effect and a slide-up effect.

## Features

- Hero section with a badge, a heading, a paragraph, and a call-to-action button
- Fade-in animation (`@keyframes fadeIn`) for the hero background and badge
- Slide-up animation (`@keyframes slideUp`) for the heading, paragraph, and button
- Animation timing adjusted with delays, so the elements appear one after another
- Navigation bar, features section with 3 cards, and footer
- Responsive layout that works on desktop and mobile screens
- Animations turn off for users who prefer reduced motion

## Animation Timing

| Element | Animation | Delay |
|---|---|---|
| Hero background | Fade in | 0s |
| Badge | Fade in | 0.2s |
| Heading | Slide up | 0.5s |
| Paragraph | Slide up | 0.9s |
| Call-to-action button | Slide up | 1.3s |

## Technologies Used

- HTML5
- CSS3 (`@keyframes`, animations, Flexbox, CSS Grid, and media queries)

## How to Run

1. Download or clone this repository.
2. Open `index.html` in any web browser.
3. Refresh the page to watch the hero animation play again.
